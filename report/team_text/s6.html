We used Folium to visualise the reconstructed routes and compare them with the actual GPS observations. We generated maps for all 10 student-test trips. These maps are available in the results/maps/ directory and were created using 06_hmm_eval.py and viz.py.

What does each map display? We used different colours to represent the different layers: grey for the road network, blue for the raw GPS observations, green for the reference route, red for the predicted route generated by the HMM, and amber for the classifier-only predictions, which can be enabled or disabled. Each map also includes a legend, layer controls, start and end markers, and automatic zooming based on the trip.

Important figures. Figure 15 shows Trip 00000056, where the HMM produced the largest improvement. Figure 16 shows a zoomed-in view of Trip 00000009. In Figure 16, we can clearly see that the amber classifier-only predictions sometimes jump between neighbouring roads. The red HMM-predicted route, on the other hand, maintains better road connectivity. This visual comparison helps demonstrate why considering road transitions is important.

Note: the screenshots included in the PDF were rendered without the basemap. However, when the HTML maps are opened in a browser, the underlying streets are visible.
